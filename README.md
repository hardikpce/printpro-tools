# PrintPro Tools

Starter website inspired by the general category and workflow of online print/PDF/photo tool platforms.

## Run locally

1. Install Node.js 20+
2. Open this folder in terminal
3. Run:
   npm install
   npm start
4. Open http://localhost:3000

## Deploy

This is an Express app. It can be deployed to a Node.js hosting service that supports `npm start`.
